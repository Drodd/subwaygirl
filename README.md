# 地铁睡神

这是一个基于Web的休闲游戏，玩家需要控制一个在地铁上打瞌睡的乘客，尽量保持平衡，不要倒向任何一侧。

## 游戏特点

- 简单有趣的游戏机制
- 逼真的物理模拟效果
- 随着时间增加的游戏难度
- 精美的图形和动画效果
- 响应式设计，适配不同设备

## 玩法说明

1. 点击"开始游戏"按钮开始游戏
2. 使用左右按钮控制角色的平衡
3. 尽可能长时间保持角色不倒下
4. 当角色倾斜超过一定角度时游戏结束
5. 游戏结束后可以查看得分并重新开始

## 技术实现

- 纯JavaScript实现的物理引擎
- HTML5 Canvas绘图
- CSS3动画效果
- 响应式设计适配各种屏幕尺寸

## 文件结构

- `index.html`：游戏主页面
- `game.js`：游戏逻辑和物理引擎
- `img/`：游戏图像资源
  - `img_bg_train.png`：地铁背景图
  - `img_bg_cloud.png`：云层背景图
  - `img_girl_body.png`：游戏角色图片
  - 其他结局画面图片
- `bgm.mp3`：游戏背景音乐

## 如何运行

1. 下载所有项目文件
2. 在浏览器中打开index.html文件
3. 点击"开始游戏"按钮即可开始游戏

## 兼容性

游戏支持大多数现代浏览器，包括：
- Chrome
- Firefox
- Safari
- Edge

最佳体验请使用移动设备或触屏设备进行游戏。
